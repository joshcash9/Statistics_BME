# Statistics_BME
Graduate Level Statistics Course with Biomedical Engineering Examples
Understanding statistical analyses is an essential skill for scientists in academia and industry. Here we will discuss the philosophy of hypothesis testing, simulate datasets via random sampling, and perform parametric and nonparametric tests. In additional to traditional tests (mean comparison, regression, ANOVA) we will also introduce some advanced techniques (mixed linear models, maximum likelihood, Bayes, bootstrapping, and MCMC). Special acknowledgement to Paul Gribble for providing his course material to build from, as well as Tony Carlsen for sharing material on LMM.
